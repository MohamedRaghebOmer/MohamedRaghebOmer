\## 📌 Selected Projects



\### 🦷 Dental Management System



A comprehensive management system built for a real dental clinic to streamline daily operations — patient management, appointments, visits, treatments, prescriptions, payments, and radiographs.



\- Applied \*\*Clean Architecture\*\*, \*\*Domain-Driven Design (DDD)\*\*, and the \*\*Repository Pattern\*\* for a scalable, maintainable backend.

\- Designed and implemented complete clinical workflows across the full patient journey.

\- Built a relational \*\*SQLite\*\* database with \*\*10+ interconnected tables\*\* using \*\*Entity Framework Core\*\*, with managed migrations.

\- Delivered for a real client, collaborating through development and post-deployment improvements.

\- Integrated \*\*Serilog\*\* for structured application logging.



\*\*Key Features:\*\* Patient Management · Appointment Scheduling · Visit \& Treatment Management · Prescription Management · Payment Tracking · Radiograph Management · EF Core Migrations · Structured Logging



\*\*Tech Stack:\*\* C#, ASP.NET Core, WinForms, Entity Framework Core, SQLite, Clean Architecture, DDD, Repository Pattern, Serilog



\*\*Demo:\*\* \[Watch on YouTube](https://www.youtube.com/watch?v=ObpU8mq26vk) · \*\*Source:\*\* \[GitHub Repo](https://github.com/MohamedRaghebOmer/Dental-Management-System)



\### 🛒 SMS — Supermarket Management System



A layered backend system for supermarket operations, covering authentication, authorization, auditing, sales, returns, customer accounts, inventory, and financial ledger tracking.



\- Built a role-based and entity-level permission system using bitwise operations for fine-grained authorization.

\- Implemented \*\*JWT\*\* authentication with secure password hashing and session management.

\- Designed a clean, scalable layered architecture separating Domain, Application, and Infrastructure concerns.

\- Developed full sales and return workflows with inventory updates and financial calculations.

\- Designed a fully normalized relational database supporting complex business workflows.



\*\*Key Features:\*\* JWT Authentication \& Refresh Tokens · Role \& Permission Management · Audit Logging · Sales \& Returns Management · Inventory Tracking · Customer Ledger System



\*\*Tech Stack:\*\* C#, ADO.NET, ASP.NET Core 10, T-SQL



\*\*Source:\*\* \[GitHub Repo](https://github.com/MohamedRaghebOmer/SMS-Supermarket-Management-System)



\### 🪪 DVLD — Driving \& Vehicle License Department



A desktop application managing the full lifecycle of driving licenses, including multi-stage testing, financial transactions, and regulatory compliance.



\- Designed a normalized database schema with relationships and constraints.

\- Built stored procedures to handle complex business logic at the database level.

\- Developed a multi-layered validation engine automating eligibility checks and preventing duplicate applications.

\- Enforced age and license-class eligibility rules while preventing conflicting requests.



\*\*Key Features:\*\* Multi-stage license workflow (Vision → Written → Practical) · Smart appointment scheduling · Automated eligibility \& validation · Duplicate/conflict prevention · Issuance, renewal, replacement \& international license support · Integrated driver/applicant management



\*\*Tech Stack:\*\* C#, ADO.NET, .NET Framework 4.8, WinForms



\*\*Source:\*\* \[GitHub Repo](https://github.com/MohamedRaghebOmer/DVLD-Driving-Vehicle-License-Department) · \*\*Demo:\*\* \[Watch on YouTube](https://youtu.be/3lIlErl78XY?si=yvqzm\_DiIOdT-x9W)
